# 🧭 My Engineering Philosophy

> **Don't just make it work. Make it understandable, reliable, scalable, and observable.**

I believe good engineering sits at the intersection of:

```text
        Product
          ▲
          │
          │
Performance ◄──► Reliability
          │
          │
          ▼
      Maintainability
```

I try to think beyond simply writing features:

**How will this scale?**
**What happens when it fails?**
**Can another developer understand it?**
**How do we monitor it?**
**Can the architecture evolve?**
